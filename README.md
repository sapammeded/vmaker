# VMaker — AI Movie Studio

Browser-first cinematic movie cockpit for Android.

## Flow
Create Movie → Character Identity → Story → Shot Plan → Model Router → AI Generation → Continuity → Timeline.

## Run
Open the GitHub Pages site or `index.html` in Chrome Android.

## AI generation
The cockpit supports an OpenRouter-compatible asynchronous video endpoint. Keep provider credentials out of public source when deploying publicly; use a secure gateway for production.

## Demo
Local Demo Render creates a WebM storyboard without an API key. It is a preview, not AI generation.
